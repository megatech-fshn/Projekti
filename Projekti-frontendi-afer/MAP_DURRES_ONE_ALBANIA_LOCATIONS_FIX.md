# Durrës Map ONE Albania Locations Fix

Updated the Durrës city map behavior so it matches the other city buttons and searches for ONE Albania store locations instead of only pinning the Durrës city center.

## Changes

- Changed `Durres.cityMapQuery` to `ONE Albania stores in Durres, Albania`.
- Enabled `showSearchPins` for Durrës so Google Maps displays matching ONE Albania location results.
- Reduced Durrës map zoom from `15` to `13` so multiple store/location results can be visible.
- Renamed Durrës store cards from `Telecom Albania` to `ONE Albania` for consistency.
