# Round Global Theme Switcher

Applied update:

- The theme control is now a fully round floating button.
- It stays visible on every page because it is injected globally by `js/script.js`.
- The theme menu opens above the button and shows the three theme choices as round icon buttons:
  - White Mode
  - Dark Mode
  - System Mode
- The chosen mode is still saved in `localStorage`.
- System Mode still follows the user's device/browser preference.
